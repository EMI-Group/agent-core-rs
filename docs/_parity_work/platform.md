## Deferred (still unimplemented)
- `openjiuwen-common` — Python's `StatusCode` enum and exception class tree (replaced by `ErrorKind` plus one `Error` enum), the `clients/` connector pools/session managers/`ClientRegistry`, AES-GCM crypto, SSRF URL checks, SSL helpers, log rotation, and invocation JSONL sinks (format/design).
- `openjiuwen-macros` — `Args:`-block parameter descriptions scraped from doc comments, flat keyword-parameter expansion, and sync/generator tool handlers (format/design).
- `openjiuwen-foundation` — `pgvector`/`postgres`/`gauss`/`gaussvector` vector backends, every external graph backend, Redis TLS/cluster, the Playwright MCP transport, the OpenAI Responses transport, DashScope streaming media and result-URL downloads, Anthropic thinking blocks in non-streaming responses, and the `output_parsers`/`system_one` packages (vendor SDK / external service / platform automation).
- `openjiuwen-session` — Python pickle checkpoint payloads, `rediss://` TLS and Redis cluster/Sentinel, the `session_controller` downstream link graph/policies/`GlobalSessionController`, git VCS backends with `rewind`/`fork`, and Python's team-session shared global lane (format/design).
- `openjiuwen-graph` — pickle-persisted Pregel internals, the `stream_actor` graph-streaming machinery, DOT/PNG/SVG rendering, and any-of/count/timeout edge trigger modes (format/design).

## Error::Unsupported surface
- `openjiuwen-common`: (none) — `Error::Unsupported` is only defined here; no path in the crate constructs it.
- `openjiuwen-foundation`: `store::external::registry` — `pgvector`/`postgres`/`gauss`/`gaussvector` and every non-local graph backend construct to `Error::Unsupported` because no PostgreSQL/GaussDB driver or network `GraphStore` contract is ported.
- `openjiuwen-foundation`: `tool::mcp` — `connect_mcp_server` rejects `McpClientType::Playwright` ("requires a browser runtime"), and `McpClient::list_resources`/`read_resource` default to `Unsupported` for transports without resource support.
- `openjiuwen-foundation`: `tool::restful` — `RestfulApiTool::stream` yields a single `Error::Unsupported` because the REST tool is single-shot.
- `openjiuwen-foundation`: `store::external::redis` — a `rediss://` URL is rejected instead of silently downgraded to plaintext.
- `openjiuwen-foundation`: `llm::factory`/`llm::registry`/`llm::routing` — an unregistered provider name is `Unsupported` (configuration validation, not a deferral).
- `openjiuwen-session`: `checkpoint::resp`/`checkpoint::redis` — `rediss://` TLS; `checkpoint::create_checkpointer` — `sqlite` without the `sqlite` feature.
- `openjiuwen-session`: `Session::install_trace_sink` default and `sessions::RouterSession` — the provided trait default reports `Unsupported`, and router views are read-only (interaction and sink installation rejected).
- `openjiuwen-graph`: (none) — every deferral here is a format/design choice, not a stubbed path.
