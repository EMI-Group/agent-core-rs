## Error::Unsupported surface
- `openjiuwen-harness`: `subagents::presets::build_preset` — the `browser`/`cua`/`mobile` presets compile only with their feature and still report the missing external worker.
- `openjiuwen-harness`: `workspace::DirectoryBuilder::build` — the configured sys-operation has no filesystem backend.
- `openjiuwen-harness-providers`: `factory::{create_harness, resolve_provider}` and `providers::{claudecode, codex, dsh}::provider` — `native_v2` lives in `openjiuwen-agent-teams`, and vendor harnesses require an SDK plus an external CLI process.
- `openjiuwen-harness-protocol`: (none) — capability gaps surface as `HarnessError::UnsupportedCapability`, not `Error::Unsupported`.
- `openjiuwen-cli`: (none) — an unknown provider reaches `Error::Unsupported` through `openjiuwen_foundation::llm::init_model`, which the CLI only forwards.
- `openjiuwen`: (none) — pure facade.
