## Deferred (still unimplemented)
- `openjiuwen-dev-tools` — zip/gzip archive unpacking (format/design); Playwright/JS rendering, stealth/cookie handling and the Pillow/multimodal image judge (platform automation); agent-builder pipeline extras (intention detector, multi-turn clarifier, three-pass designer, DL refine mode, resource retrieval, streaming) and `tune` dataset samplers/`chat_agent` adapters (ML/research stack).
- `openjiuwen-symphony` — faiss + sentence-transformers experience index and `transformers`/vLLM logit-based branch selection (ML/research stack); GCS and Azure Blob artifact transports (external service).
- `openjiuwen-rsi` — `agentdescent` 0.4.6 evolve/ledger/aggregator internals (ML/research stack); guarded judge-model plumbing and its prompts (`deferred::LlmJudgeEvaluator`, ML/research stack); synthetic `sys.modules` hot-loading (`deferred::RuntimeExtensionLoader`, format/design); live LLM stage/DeepAgent orchestration left to the caller's `HarnessRunner` (ML/research stack); `infra::{github_cli,skill_source_manager}` shelling out to `gh`/the network (platform automation).
- `openjiuwen-agent-evolving` — RL trainer on `torch`/`transformers`/`verl`/`ray` (ML/research stack); Redis/vLLM online RL state machine and the `agent_rl` proxy/judge/verification gateway (external service); remote sharing hub client (external service); vendor browser/PIL reward checks (platform automation); LLM experience drafting and TTSE embedding/LLM dreaming (ML/research stack); the full verl/ray YAML config ecosystem (format/design).
- `openjiuwen-auto-harness` — none of its own; it re-exports the canonical surface and inherits the `openjiuwen-rsi` deferrals (format/design).

## Error::Unsupported surface
- `openjiuwen-dev-tools`: `skill_creator::omni::ArchiveUnpacker` for `ArchiveFormat::{Zip,Gzip}` — decompression needs a crate outside the pinned offline dependency set (plain ustar `tar` is implemented).
- `openjiuwen-symphony`: `deferred::FaissExperienceIndex` — faiss/sentence-transformers index; `deferred::VllmLogitSelector` — GPU `transformers`/vLLM inference; `object_artifact::ArtifactTransport::{Gcs,AzureBlob}` — no such transport is shipped; `orchestration::UnsupportedRunner` — execution without an injected `CapabilityRunner`; `evaluation::LlmJudgedMetric` — the static suite's judge metric is a stub while `llm::LlmJudgeMetric` carries the model-backed verdict.
- `openjiuwen-rsi`: `deferred::EvolutionEngine` — `agentdescent` internals have no maintained Rust equivalent; `deferred::LlmJudgeEvaluator` — a guarded judge model belongs to the harness layer; `deferred::RuntimeExtensionLoader` — `sys.modules` hot-loading has no Rust analogue.
- `openjiuwen-agent-evolving`: `rl::OfflineRlOptimizer::{train,start_training}` — Python PPO/verl/ray stack (`train_with` drives the portable `RlTrainer`); `rl::OnlineRlOptimizer::{start_training,train_on_batch}` — Redis/vLLM gateway, with the axum RL routes answering `501`; `evaluator_pipeline` — a missing `docker` or command binary is reported as `Error::Unsupported` instead of being skipped.
- `openjiuwen-auto-harness`: none of its own (it defines only `crate_name()` besides the re-exports).
